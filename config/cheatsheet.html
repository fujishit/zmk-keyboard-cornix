Cornix チートシート

config/cornix.keymap から自動生成。キーの数字は ZMK のキー位置（0-49）で、scripts/remap.py で使う番号と同じ。キーにカーソルを合わせると元のバインディングが出る。

46 押しながら
Fn2（F キー・ナビ）
45 押しながら
Fn3（マウス）
45+46 両方押しながら
Conn（接続切り替え。両方押すと自動で出る）
Win レイヤー
OS 検出が Windows/Linux を見つけると自動。手動は 45+0（&tog 1）

音量アップ / ダウン
エンコーダ（右）
スクロール（1 ノッチ 3 ホイール単位）

左親指は 41 Cmd/Ctrl・42 Num・43 Space、右親指は 44 Space・45 Fn3・46 Fn2。

Mac と Windows の違い

41（左親指）
macOS では Cmd、Windows では Ctrl
39
macOS では Cmd、Windows では Windows キー（LGUI のまま）
38
どちらも Ctrl（変わらない）
41+Tab
macOS は Cmd+Tab、Windows は Alt+Tab。41 を押している間はスイッチャーが開いたまま（app_tab が Alt を本物の修飾キーとして保持）
Ctrl+Space
IME 切り替え。macOS は既定、Windows は IME 側の設定で割り当てる

接続まわり

45+46 を両方押しながら…
Conn レイヤー。覚え方：左端の列が上から USB → Bluetooth、その隣の列が上からプロファイル 0 → 1 → 2
…0（Tab の位置）
USB 出力に切り替え（&out OUT_USB）
…12（Caps の位置）
BLE 出力に切り替え（&out OUT_BLE）。USB 接続中は 45 秒の猶予ウィンドウの間だけ広告が許される
…1 / 13 / 25（Q / A / Z の位置）
BT プロファイル 0 / 1 / 2 を選択
45+0
Win レイヤーの手動トグル（OS 検出が外れたとき。Fn3 単独）

LED の意味（cornix_indicator シールドを載せた場合。左半分は LED0 が接続・LED1 が電池、右半分は逆）

LED状態見え方
接続 LEDUSB 出力を選択中シアン点灯（ケーブル接続中はつきっぱなし）
接続 LEDBT プロファイル接続プロファイル色（0 緑 / 1 赤 / 2 青）1.5 秒、USB 給電中は継続
接続 LED相手を探している（広告中）プロファイル色でゆっくり明滅、電池駆動なら 5 秒で消灯
接続 LED接続が切れたプロファイル色で 0.5 秒点滅、電池駆動なら 3 秒で消灯
接続 LED右半分 / ドングル側の分割リンク青：接続で 1.5 秒点灯、切断で 3 秒点滅
電池 LED残量レポート（60 秒ごと）緑 >80% / 黄 20-80% / 赤 ≤20% を 2 秒
電池 LED充電中 / 充電完了緑の明滅 / 99% 以上で緑点灯

色の凡例

  • 文字・記号
  • 修飾キー
  • レイヤーキー
  • マウス
  • 接続・メディア
  • 専用ビヘイビア
  • 下の層のまま

Base (layer 0)

既定レイヤー（macOS 向け）。何も押していないときはこれ。

← 横にスクロールできます →

Win (layer 1)

OS 検出が Windows/Linux を見つけると自動で重なる差分レイヤー。色の薄いキーは Base のまま（&trans）。

← 横にスクロールできます →

Num (layer 2)

42（左親指の内側）を押している間。数字と記号。

← 横にスクロールできます →

Fn2 (layer 3)

46（右親指の内側）を押している間。F キー・ナビゲーション。

← 横にスクロールできます →

Fn3 (layer 4)

45（右親指）を押している間。マウス。

← 横にスクロールできます →

Conn (layer 5)

45 と 46（右親指の Fn キー 2 つ）を両方押している間だけ自動で重なる条件レイヤー（conditional_layers）。接続切り替え専用で、左端の列が USB / BLE、その隣の列が BT プロファイル 0 / 1 / 2。それ以外のキーは下の層のまま。

← 横にスクロールできます →

図にしていないレイヤー

MouseSlow、MouseFast は図にしていません。MouseSlow(6) と MouseFast(7) は全部 &trans で、キーは 1 つも持ちません — Fn3 の W / E が立てるフラグで、&mmv_input_listener のスケーラを 1/2 倍・2 倍に切り替えるためだけに存在します。
